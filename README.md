# Meal Finder

A simple React app that displays chicken meals from TheMealDB. The homepage loads meals from `https://www.themealdb.com/api/json/v1/1/search.php?s=chicken`, and the search box filters the returned chicken meals. Select a meal to view its recipe details.

## Run the project

1. Install Node.js.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.
